# /aidd-competitive-scan — Competitive intelligence

Target: $ARGUMENTS

## Sequence

1. Confirm the tool or category (for example Sourcegraph, CodeSee, Sourcetrail, GitHub code navigation, Snyk Code).
2. **diane-competitive-analyst**:
   - Sourced research: positioning, key features, pricing, target user
   - Comparison with Graph-It-Live (analyzer, MCP, webview, CLI): gaps and advantages
   - Matrix (feature | them | us)
3. Strategic recommendation: feature to prioritize, differentiator to strengthen, or justified non-priority.
4. Save to `docs/strategy/competitive-<tool>.md`.

## Rule

Never copy protected code or content; factual synthesis with cited sources. Separate verified facts from marketing claims.
