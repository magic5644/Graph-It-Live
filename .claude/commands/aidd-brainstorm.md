# /aidd-brainstorm — Ideation

Idea: $ARGUMENTS

## Sequence

1. **julie-requirements-analyst**: problem space — impacted actors, needs addressed, three phrasings of the value.
2. **romain-requirements-devil**: challenge the idea itself — why not do it, what already covers the need, scope-creep risk.
3. **ines-performance-analyst**: quick feasibility — fit with the layers, estimated WASM/performance impact.
4. The main conversation presents three options:
   - A: direct implementation (with estimate)
   - B: reduced version / MVP
   - C: do not implement (with reason)
5. **The human chooses.** Go → `/aidd-clarify` with the initial brief.

## Rule

No code, no spec. Output: go/no-go decision and initial brief.
