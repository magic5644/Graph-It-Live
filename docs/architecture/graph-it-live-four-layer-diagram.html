Graph-It-Live Architecture

Four-layer architecture: analyzer · extension · mcp · webview + shared

Critical Rules

  • • No vscode imports in analyzer/ or mcp/
  • • Extension ↔ webview protocol lives in shared/types.ts
  • • Service layer in extension/services/ handles all orchestration
  • • Update both message-protocol sides when adding commands

Dual Bundles

  • • dist/extension.js — VS Code extension
  • • dist/graph-it.js — Standalone CLI
  • • dist/webview.js — File/symbol graph app
  • • dist/callgraph.js — Call graph panel app

Dual-Level Analysis

  • • File-level: fast regex import parsing
  • • Symbol-level (AST): ts-morph + WASM tree-sitter
  • • Symbol-level (LSP): VS Code call hierarchy providers
  • • Cross-file: Live Call Graph via sql.js SQLite
